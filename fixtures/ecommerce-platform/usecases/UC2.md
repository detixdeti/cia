# UC2: Benutzer anmelden

Ziel: Ein registrierter Benutzer meldet sich am System an.

Vorbedingung: Ein aktives Benutzerkonto existiert.

Ablauf:
1. Der Benutzer uebergibt E-Mail und Passwort.
2. Das System authentifiziert die Anmeldedaten.
3. Eine neue Benutzersitzung wird erzeugt.

Erfolgsbedingung: Die Sitzung ist aktiv und der Benutzer eingeloggt.
