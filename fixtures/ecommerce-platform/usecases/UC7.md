# UC7: Zwei-Faktor-Authentifizierung aktivieren

Ziel: Der Benutzer richtet 2FA fuer sein Konto ein.

Ablauf:
1. Das System generiert ein 2FA-Secret und einen QR-Code.
2. Der Benutzer gibt einen Bestaetigungscode ein.
3. 2FA wird fuer das Konto scharfgeschaltet.

Erfolgsbedingung: Kuenftige Logins erfordern den zweiten Faktor.
