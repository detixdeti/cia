# UC5: Lieferadresse hinzufuegen

Ziel: Eine zusaetzliche Lieferadresse wird im Profil hinterlegt.

Ablauf:
1. Der Kunde gibt Strasse, Hausnummer, PLZ und Ort ein.
2. Das System validiert die Postadresse.
3. Die Adresse wird dem Kundenkonto zugeordnet.

Erfolgsbedingung: Die Adresse ist fuer zukuenftige Bestellungen verfuegbar.
