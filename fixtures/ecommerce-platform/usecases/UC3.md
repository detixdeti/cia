# UC3: Passwort zuruecksetzen

Ziel: Ein Benutzer fordert ein neues Passwort an.

Vorbedingung: Das Konto existiert.

Ablauf:
1. Der Benutzer gibt seine E-Mail-Adresse an.
2. Das System generiert ein zeitlich begrenztes Token.
3. Ein Link zum Zuruecksetzen wird per E-Mail gesendet.

Erfolgsbedingung: Das Passwort kann neu gesetzt werden.
