# UC13: Exemplar aussondern

Ziel: Ein beschaedigtes oder veraltetes Exemplar wird aus dem Bestand entfernt.

Ablauf:
1. Der Mitarbeiter gibt die ISBN des Titels ein.
2. Das System prueft, dass ein Exemplar verfuegbar ist, also nicht entliehen.
3. Das System entfernt ein Exemplar aus dem Bestand.
4. War es das letzte Exemplar, entfernt das System den Titel aus dem Katalog.

Erfolgsbedingung: Der Bestand ist um ein Exemplar verringert.

Regel: Das letzte Exemplar eines vorgemerkten Titels darf nicht ausgesondert werden.
