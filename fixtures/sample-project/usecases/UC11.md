# UC11: Mitgliedschaft verlaengern

Ziel: Ein Mitglied verlaengert seine Mitgliedschaft um ein Jahr.

Vorbedingung: Das Mitglied hat keine offenen Gebuehren.

Ablauf:
1. Der Mitarbeiter waehlt das Mitglied aus.
2. Das System berechnet den Jahresbeitrag.
3. Das Mitglied bezahlt den Beitrag.
4. Das System verlaengert die Mitgliedschaft um ein Jahr ab dem bisherigen
   Ablaufdatum, bei bereits abgelaufener Mitgliedschaft ab heute.
5. Das System erstellt eine Quittung.

Erfolgsbedingung: Die Mitgliedschaft ist ein weiteres Jahr gueltig.

Regel: Der Jahresbeitrag betraegt 12,00 EUR. Ermaessigte Mitglieder zahlen die
Haelfte.
