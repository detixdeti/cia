# UC12: Neuzugang erfassen

Ziel: Ein neuer Titel oder weitere Exemplare werden in den Bestand aufgenommen.

Ablauf:
1. Der Mitarbeiter erfasst ISBN, Titel, Autor und Anzahl der Exemplare.
2. Das System prueft die ISBN-13 anhand der Pruefziffer.
3. Ist die ISBN bereits im Bestand, erhoeht das System die Anzahl der Exemplare.
4. Andernfalls legt das System einen neuen Titel an.

Erfolgsbedingung: Die Exemplare sind im Bestand und sofort ausleihbar.

Regel: Es muss mindestens ein Exemplar erfasst werden. Bindestriche und
Leerzeichen in der ISBN werden ignoriert.
