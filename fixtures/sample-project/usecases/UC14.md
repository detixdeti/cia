# UC14: Monatsstatistik erstellen

Ziel: Die Bibliotheksleitung erhaelt Kennzahlen fuer einen Monat.

Ablauf:
1. Die Leitung waehlt einen Monat aus.
2. Das System zaehlt die Ausleihen und Rueckgaben des Monats.
3. Das System zaehlt die zum Monatsende ueberfaelligen Ausleihen.
4. Das System ermittelt die Summe aller offenen Gebuehren.
5. Das System gibt die Kennzahlen als Text aus.

Erfolgsbedingung: Die Statistik fuer den gewaehlten Monat liegt vor.
