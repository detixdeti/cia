# UC5: Bestand durchsuchen

Ziel: Ein Titel wird im Bestand gefunden.

Ablauf:
1. Der Anwender gibt einen Teil des Titels ein.
2. Optional gibt er zusaetzlich einen Teil des Autornamens ein.
3. Das System liefert die passenden Titel.
4. Auf Wunsch beschraenkt das System die Trefferliste auf verfuegbare Titel.

Erfolgsbedingung: Die Trefferliste enthaelt alle passenden Titel des Bestands.
