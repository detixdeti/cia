# UC3: Mitglied anlegen

Ziel: Eine Person wird als Mitglied aufgenommen.

Ablauf:
1. Der Mitarbeiter erfasst Name und Mitgliedsnummer.
2. Das System legt das Mitglied mit dem heutigen Beitrittsdatum an.
3. Das Mitglied ist zunaechst nicht gesperrt.

Erfolgsbedingung: Das Mitglied ist angelegt und kann ausleihen.
