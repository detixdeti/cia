# UC3: Mitglied anlegen

Ziel: Eine Person wird als Mitglied aufgenommen.

Ablauf:
1. Der Mitarbeiter erfasst Mitgliedsnummer, Name und optional eine E-Mail-Adresse.
2. Der Mitarbeiter gibt an, ob das Mitglied ermaessigt ist (Schueler, Studierende).
3. Das System prueft, dass die Mitgliedsnummer noch nicht vergeben ist.
4. Das System prueft, dass eine angegebene E-Mail-Adresse ein @ enthaelt.
5. Das System legt das Mitglied mit dem heutigen Beitrittsdatum an.

Erfolgsbedingung: Das Mitglied ist angelegt, nicht gesperrt und seine
Mitgliedschaft ist ab heute ein Jahr gueltig.
