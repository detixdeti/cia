# UC10: Gebuehren bezahlen

Ziel: Ein Mitglied begleicht offene Gebuehren an der Ausleihtheke.

Vorbedingung: Fuer das Mitglied sind Gebuehren offen.

Ablauf:
1. Der Mitarbeiter waehlt das Mitglied aus, das System zeigt die offenen Gebuehren.
2. Der Mitarbeiter erfasst den gezahlten Betrag.
3. Das System verrechnet die Zahlung mit den aeltesten Gebuehren zuerst.
4. Sind danach alle Gebuehren beglichen, hebt das System eine Sperre auf.
5. Das System erstellt eine Quittung mit gezahltem Betrag, Rueckgeld und Restbetrag.

Erfolgsbedingung: Die Zahlung ist verbucht.

Regel: Teilzahlungen sind erlaubt. Eine Sperre wird erst aufgehoben, wenn alle
Gebuehren beglichen sind.
