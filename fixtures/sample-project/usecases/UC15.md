# UC15: An Rueckgabe erinnern

Ziel: Mitglieder werden vor Ablauf der Leihfrist erinnert.

Ausloeser: Taeglicher Lauf des Systems.

Ablauf:
1. Das System ermittelt alle offenen Ausleihen, die in drei Tagen faellig werden.
2. Das System sendet dem Mitglied eine E-Mail mit Titel und Faelligkeitsdatum.
3. Das System zaehlt die versendeten Erinnerungen.

Erfolgsbedingung: Alle betroffenen Mitglieder mit E-Mail-Adresse sind erinnert.

Regel: Mitglieder ohne E-Mail-Adresse erhalten keine Erinnerung.
